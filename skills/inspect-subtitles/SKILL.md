# inspect-subtitles

Use the subtitle viewer for selected file or text. Render payloads as text, not HTML. Inspect timestamps and segment numbers, search locally and select excerpts. Do not execute markup or fetch cue links. Preserve the original and report malformed cues rather than silently repairing them. Use selected text as chat context only on an explicit action. Never save changes to the source from this read-only workflow.
